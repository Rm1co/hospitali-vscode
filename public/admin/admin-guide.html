📚 Getting Started

  1. First Time Setup: Run setup-admin-system.html to initialize the database
  2. Login: Use the default Super Admin credentials (admin / Admin@123)
  3. Change Password: Immediately change the default password for security
  4. Create Admins: Create additional admin accounts with appropriate roles
  5. Manage Staff: Use staff management to add doctors, nurses, and other hospital staff

🔐 Security Best Practices

  • Change default Super Admin password immediately
  • Use strong passwords (minimum 8 characters)
  • Create specific accounts for each administrator
  • Assign minimum necessary permissions
  • Deactivate accounts when staff leaves
  • Review admin activity regularly
